# OOP Final Project — Rich Library

Object-oriented design coursework completed at The Islamia University of Bahawalpur.

## Group
Mohsin Atta, Qazi Reyan, Rehan Bukhari.

## Project
We analyzed the Python `rich` terminal formatting library and implemented a `StudentDashboard` subclass of `rich.table.Table`.

## Run
```bash
python -m pip install rich
python oop_rich_project/code/custom_extension.py
```

## Project materials
- `oop_rich_project/code/custom_extension.py`: dashboard code
- `oop_rich_project/diagram/uml diagram.png`: UML diagram
- `oop_rich_project/report/report.pdf`: written report
- `oop_rich_project/presentation/presentation.pdf`: presentation

The example displays a formatted student task table in the terminal, not a game menu.
